# CarePOS 심볼 시안 · 투표 페이지

Figma의 「케어포스 브랜드 디자인 › 심볼 시안」 섹션을 웹페이지로 옮긴 정적 사이트입니다.
4개 심볼 시안(케어 카운터 / 틸트 터미널 / 네이밍 표기 워드마크 / 케어 모니터)을 소개하고,
페이지 하단에서 **로고 투표**와 **간단한 의견 남기기**를 할 수 있습니다.

- 호스팅: GitHub Pages (이 저장소의 `main` 브랜치 루트)
- 투표/의견 저장: Firebase Realtime Database (`polls/carepos-logo-vote` 경로)
- 기기당 1표, 다른 시안을 누르면 선택이 바뀝니다. 이름은 선택 입력입니다.
- **투표와 의견은 담당자 공개키로 암호화되어 저장**됩니다. 투표는 RSA-OAEP로 직접, 의견은 의견마다 AES-GCM 키를 만들어 본문을 암호화하고 그 키를 RSA-OAEP로 잠급니다. DB를 직접 열어도 내용을 알 수 없습니다.
- 중복 투표가 허용됩니다. 카드 선택 → 투표하기 → 확인 창 순서로 1표가 추가됩니다.
- 참여자 화면에는 득표수와 의견 목록이 보이지 않고, 총 표수와 의견 건수만 표시됩니다.
- 집계와 의견은 `results.html`에서 담당자 개인키(`admin-private-key.json`, 저장소에 포함되지 않음)를 불러와 브라우저 안에서 복호화해 확인합니다. 개별·전체 삭제와 CSV 내려받기도 이 페이지에서 합니다. 개인키를 잃어버리면 기존 표를 복호화할 수 없으니 안전한 곳에 보관하세요.
- 네트워크 문제로 DB에 연결되지 않으면 해당 기기에만 저장되는 오프라인 모드로 동작합니다.

## 구조

```
index.html          페이지 본문 + 스타일 + 투표(암호화)/의견 스크립트
results.html        담당자용 결과 페이지 (개인키로 복호화·집계, 링크 비공개)
assets/symbol-0N.svg  시안 심볼 (Figma 벡터 레이어 그대로)
assets/wordmark.svg   CarePOS 워드마크
```
